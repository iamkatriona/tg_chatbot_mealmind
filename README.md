# tg_chatbot_mealmind
Chat-bot in Telegram for university project.

Бот MealMind - это Telegram-бот для планирования питания с учетом пищевых ограничений. Основные функции:

1. **База данных SQLite**:
   - Использует файл `database_mm.db`
   - 3 таблицы:
     - `users` (ID пользователя, ограничения: мясо/лактоза/цитрусы)
     - `recepies` (рецепты с атрибутами и ограничениями)
     - `likes` (избранные рецепты пользователей)

2. **Основные команды**:
   - `/start`: 
     - Регистрирует пользователя в БД
     - Спрашивает о необходимости добавить ограничения в питании
     - Предлагает кнопки "Да/Нет"

   - `/hungry`:
     - Показывает инлайн-клавиатуру для выбора типа приема пищи (завтрак/обед/ужин)
     - Выдает случайный рецепт с учетом ограничений

   - `/favourites`:
     - Показывает список избранных рецептов пользователя

3. **Система ограничений**:
   - Последовательный опрос об ограничениях:
     1. Мясо (да/нет)
     2. Лактоза (да/нет)
     3. Цитрусовые (да/нет)
   - Сохраняет выбор в БД

4. **Работа с рецептами**:
   - При выборе типа пищи:
     - Ищет рецепт с учетом ограничений пользователя
     - Выводит название, ингредиенты и шаги приготовления
     - Предлагает кнопки:
       - ❤️ (добавить в избранное)
       - ⏭️ (следующий рецепт)

5. **Особенности реализации**:
   - Динамическое обновление сообщений через `edit_message_text`
   - Использование emoji для кнопок
   - Случайный подбор рецептов (`ORDER BY RANDOM()`)
   - Защита от дублирования в избранном (`DISTINCT`)
   - Обработка текстовых сообщений: "Больше мне такое не отсылай"

### Принцип работы
1. Пользователь запускает бота (`/start`), настраивает ограничения
2. Когда голоден - вызывает `/hungry` и выбирает тип приема пищи
3. Получает случайный подходящий рецепт
4. Может сохранить понравившийся рецепт в избранное
5. Просматривает избранное через `/favourites`
